Extension missing from Safari?
  1. Keep ReelsBlocker in Applications and open it once.
  2. For an unsigned local build, enable Safari → Settings → Advanced → Show features for web developers, then Developer → Allow unsigned extensions.
  3. Return to Extensions, select Reels Blocker and enable its checkbox. Allow access to facebook.com and youtube.com.

Safari discovers the extension from this app. Dragging the app icon into the Extensions list does not install it.
