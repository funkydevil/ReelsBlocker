Can’t find the extension?
  1. Keep one copy of ReelsBlocker in Applications and open it once.
  2. For an unsigned local build, turn on Safari → Settings → Advanced → Show features for web developers, then Developer → Allow unsigned extensions.
  3. Return to Extensions and tick Reels Blocker for Facebook.

Safari adds the extension from this app automatically. There’s nothing to drag into the list.
